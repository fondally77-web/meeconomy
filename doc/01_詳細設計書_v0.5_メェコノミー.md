## 1. コンセプト

### 1.1 一言コンセプト

> 「刈るか、肉にするか。羊がマフラーとジンギスカンとコインに変わるのを眺める15分」

### 1.2 本作の核：羊の二択

羊は豚と違い、**生かして毛を刈り続ける**ことができる。

| 選択 | 特徴 | 経営的な意味 |
| --- | --- | --- |
| ✂️ 毛を刈る | 2ヶ月に1回、羊毛が取れる。羊は残る | **資産を持ち続けて小さく稼ぐ**（ただし毎月エサ代がかかる＝保有コスト） |
| 🔪 肉にする | 一度きりで大きな売上。羊は消える | **資産を現金化する**（エサ代は消えるが、来月から毛も取れない） |

毎月「群れの何頭を刈り、何頭を出荷するか」を決めるのが本作最大の意思決定。**持ち続けるか、現金化するか**という経営のド真ん中の問いが、羊1頭のかわいい二択に化ける。

### 1.3 二股パイプライン

```
                ┌─✂️→ 🧶ウール社(毛→糸) → 👕アパレル社(糸→服) ─┐
🐑ファーム(飼育)─┤                                              ├→ 🏪セールス → 🛒市場
                └─🔪→ 🥩ミート社(羊→ラム肉) → 🍖デリカ社(加工) ─┘
        すべての区間の輸送 = 🚚ロジ（トラック共有） ／ ☁️管理 = プレイヤー＋テクセル
```

- ラム肉と糸は**直販ルート**もあり（加工を通すほど高いが、能力とトラックを食う）
- **季節が逆相**：肉ライン＝夏が旬（BBQ・ジンギスカン）、ウールライン＝冬が旬（マフラー・セーター）。1ランの中で主力ラインを乗り換えるリズムが生まれる
- **鮮度が対照的**：肉は2ヶ月で廃棄、**服と糸は腐らない**（ただし季節を外すと売れない）。「腐る在庫」と「腐らないが寝る在庫」の対比＝在庫リスクの2類型を体感

### 1.4 学習目標（体感ベース）

| # | 体感 | 背景概念 |
| --- | --- | --- |
| L1 | 羊毛→糸→マフラーと値段が上がる | 付加価値・原価の積み上げ |
| L2 | 単純合計より連結が小さい（毎月リザルトで対比） | 内部取引と連結消去 |
| L3 | 刈るか肉か、エサ代を払い続けるか | 資産の保有コストと現金化・キャッシュフロー |
| L4 | 詰まると在庫が溜まる／肉は腐り、服は季節を外すと寝る | ボトルネック・在庫リスク |
| L5 | トラックが足りないとモノもお金も動かない | 物流費・リードタイム |
| L6 | 帳簿ズレ探しで売り手と買い手を突合 | 債権債務照合・入力統制 |
| L7 | 図鑑のSAPカード | Tコード・テーブルの入口 |

## 2. コアループ（v0.4継承・差分のみ）

### 2.1 ラン構造

1ラン＝1年度（4月〜3月・12ターン）≒15分。毎月：指示フェーズ（タップ）→フローフェーズ（鑑賞30秒）→月末リザルト（1画面）。年度末に決算スコア→ランク→のれんP→ラボ強化→次のラン。

### 2.2 指示フェーズ（月10〜15タップ＋おまかせボタン）

| 会社 | 指示 |
| --- | --- |
| 🐑ファーム | 子羊の導入数／**毛刈りする頭数／出荷（肉行き）する頭数** |
| 🥩ミート | と畜数（羊1頭→ラム肉2箱） |
| 🍖デリカ | レシピ別加工数（ジンギスカン等） |
| 🧶ウール | 紡績数（羊毛1袋→糸2巻） |
| 👕アパレル | レシピ別生産数（マフラー等） |
| 🏪セールス | 価格3択（強気/標準/弱気）＋直販比率 |
| 🚚ロジ | 7区間へのトラック割当 |

- 毛刈りは**同じ羊につき2ヶ月に1回**（クールダウン。羊アイコンに✂️マークで可視化）
- 羊は毎月エサ代がかかる（頭数×固定額）。「飼いすぎると固定費で沈む」がファームの学び

### 2.3 月末リザルト（1画面・v0.4様式を7社に拡張）

各社ミニP/L1行×7社＋「たんじゅん合計 vs グループれんけつ★」の対比＋グループ現金＋テクセル一言。★タップで内部取引の消去内訳。

### 2.4 画面上部ヘッダー（常時表示・確定仕様）

```
┌─────────────────────────────────┐
│ 💰 34,200G   🗓 7月   ⚾メェーズ 3位(+2)  🔔2 │
└─────────────────────────────────┘
```

- **⚾メェーズ帯は常時表示**：シーズン中（4〜9月＋10月優勝決定）は「順位（貯金）」、オフは「キャンプ中⛺」等の小ネタ表示
- タップで球団ミニ画面（月次ニュースのログ＋チーム力＋優勝履歴）
- 🔔は通知フィード（テクセル発言・イベント・ニュースが溜まる場所）

## 4. メェーズ（ボールパーク要素・確定仕様）

| 要素 | 仕様 |
| --- | --- |
| ペナント帯 | §2.4のとおり**画面上部に常時表示**（順位＋貯金） |
| 月次ニュース | 月1行、通知フィードに配信（例：「⚾メェーズ、8月は14勝9敗！2位に浮上」） |

| 優勝（10月判定） | 11月「ありがとう優勝セール」：需要×1.8・単価×0.88。**優勝時はアパレルに「応援マフラー特需」**（羊の球団×ウール事業のシナジー） |
| 采配 | 不可。ラボ「補強」でチーム力のみ強化 |
| スタジアム契約（ラボ） | 4〜9月ジンギスカン固定需要＋10〜3月応援マフラー固定需要（年間安定枠） |

## 6. 技術設計（差分のみ）

- スタック継続（React18+TS+Vite/Zustand/PWA/Netlify/Vitest）。内部は仕訳エンジン＋利益センタ（companyId付き仕訳）で駆動し、ミニP/L・連結・ズレ探しを単一ソースから導出
- **FlockState**：羊は「群れ」として頭数＋毛刈りクールダウン別のバケット管理（個体管理はしない。`{ readyToShear: n, cooldown1: n, cooldown2: n }` の3バケットを月次でシフト）
- 二股化でルートが7区間になるため、配車UIは「区間リスト＋−ボタン」式を維持しつつ**「自動配分」ボタン**（在庫比例で按分）を追加
- 乱数シード・メタ分離保存・ボット検証（idle/balanced/woolOnly/meatOnly）は02の基準に従う
