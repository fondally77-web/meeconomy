## 5. テスト計画

### 5.1 経済エンジン単体（P1受け入れ）

- [ ] 全仕訳の貸借一致（不一致throw）
- [ ] 単純合計 − 消去 = 連結 が全月成立
- [ ] 内部取引：farm→meat（羊1,500G）で両社の売上/仕入が金額一致
- [ ] **FlockStateシフト**：刈った羊が2ヶ月後にreadyへ戻る／出荷で総頭数減／エサ代=総頭数×200
- [ ] 毛刈り上限：ready数と毛刈り班capacityの小さい方で丸め
- [ ] 移動平均原価（羊毛→糸→マフラーの原価積み上げが検算一致：02_§12）
- [ ] 鮮度：ラム肉2ヶ月で廃棄仕訳／羊毛・糸・服・カレーは廃棄されない
- [ ] 輸送：7区間の割当×積載超過分は滞留
- [ ] 季節係数：肉系とアパレル系が別枠で適用される
- [ ] 現金連続性と敗北フラグ／スコアボーナス7種（両ライン黒字含む）の発火

### 5.2 プロセス・イベント

- [ ] ズレ生成4型で「正解行以外は完全一致」保証
- [ ] メェーズ：チーム力50で優勝率13〜17%（1000シーズン）／ヘッダーラベルの全phase遷移
- [ ] 優勝セール：需要×1.8・単価×0.88＋マフラー特需の同時適用
- [ ] 暖冬/寒波は11-2月のみ、BBQブームは7-9月のみ発火

### 5.3 バランス（P2受け入れ・02_§11）

- [ ] idle黒字率60〜75%／balancedが最良／woolOnlyは低リスク低リターン／meatOnlyは夏強・年間で劣後
- [ ] 1ラン所要時間 ≦16分（指示タップ数×秒＋フロー30秒×12で検算）

### 5.4 体験テスト（P4）

- [ ] 10〜20代被験者1名以上：説明なしで初ラン完走／「もう1回」が出るか／「刈るか肉か」の二択が伝わっているか
- [ ] iOS Safari / Android Chrome 実機60fps
