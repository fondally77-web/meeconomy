## 5. 市場需要モデル

```
月間需要(箱) = 基礎需要 × 季節係数 × ブランド係数 × イベント係数
基礎需要：肉系40箱／アパレル系30箱（別枠で判定）
価格3択：強気(×1.15・売残率+20%) / 標準 / 弱気(×0.9・需要+15%)
```

## 12. 検算メモ（初期バランスの妥当性）

- 羊1頭を1年飼って毛だけ（年6回刈り）：羊毛6袋→糸12巻→マフラー6着=15,600G売上、対して導入800＋エサ2,400＋刈毛300＋紡績1,800＋縫製1,200＋輸送・販促≒8,000G前後 → 粗利約7,000G/頭・年
- 同じ羊を即出荷：ラム肉2箱→ジンギスカン1セット3,600G＋直販1,400G、コスト≒2,600G → 粗利約2,400G/頭・即時
- → **時間をかければ毛が勝ち、現金が欲しければ肉**という設計意図どおりの数値関係。simで微調整する
